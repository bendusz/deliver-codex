## Scope contract

`prepareReviewScope(root,{scope,base,paths,limits})` produces schema_version, scope, resolved
base ref/OID/merge-base, head OID, requested paths, authoritative changes, content identity and
limits. Recent uses HEAD parent; branch requires explicit integration base and records merge-base;
worktree includes staged/unstaged and bounded regular untracked files without index mutation;
codebase manifests bounded tracked/nonignored regular content. Exact modes/OIDs/requested paths,
statuses/diff and untracked bytes, including missing requested paths, bind canonical SHA-256.
Reject traversal, protected .git/.deliver paths, symlink/nonregular/FIFO, overflow/truncation and
invalid scope. No fetch, model, remote, index or project-state writes. Git probes are timed out.
CLI uses bounded regular paths JSON or repeated paths, no stdin, and emits JSON.
