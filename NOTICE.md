# Provenance

This Codex-first implementation adapts workflow concepts and instructions from
Ben Vegh's Deliver, formerly pm-skill, at revision
`d9d107ad99d3951499c42d33dcbccb46dcd5f060`, version 0.22.0.
Upstream: https://github.com/bendusz/deliver
The shared-state adapter preserves its actor identity algorithm and PM record conventions.
Source-only tests include attributed, unchanged upstream templates and hook readers.

The original repository remains unchanged. This distribution retains GPL-3.0-or-later
licensing. No Poteto or SpecDD plugin source is bundled. SpecDD support is an independently
written, limited compatibility checker against the public language documentation, not an
